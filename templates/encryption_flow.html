🔐 Encryption Illustration

Visual representation of how files are encrypted, stored, decrypted and accessed in Secure File Vault.

1. User File Encryption Flow

This is the process used when a logged-in user uploads a file.

👤
User Logged-in user
→
📁
Select File User uploads a file
→
⚙️
Flask Application Receives file data
→
🔒
Fernet Encryption File data is encrypted
→
🗄️
PostgreSQL Encrypted bytes stored
🔑 Encryption uses the application's FERNET_KEY

2. File Decryption & Download Flow

When the owner downloads a file, the encrypted data is decrypted only after authentication and ownership verification.

👤
Authenticated User Requests download
→
🛡️
Access Check Authentication + ownership
→
🗄️
Encrypted Data Retrieved from PostgreSQL
→
🔓
Fernet Decryption Data decrypted in memory
→
⬇️
File Download Decrypted file sent to user
Security: Uploaded files are stored as encrypted data in PostgreSQL. The application does not store the original uploaded plaintext file on disk or in the database.

Security Components

🔑 Fernet Key

Secret encryption key used to encrypt and decrypt protected file data.

🗄️ PostgreSQL

Stores uploaded files as encrypted BYTEA data together with file metadata.

🛡️ Access Control

Authentication and ownership checks control who can access uploaded files.
