📘 Definitions

Vault Password

Password used to authenticate the user and unlock the Pro Vault.

Vault Key

A randomly generated 32-byte key used for Version-2 file encryption and decryption.

Version 1

The original vault format using PBKDF2-SHA256 with 600,000 iterations and AES-GCM encryption.

Version 2

The updated vault format using the protected vault key with AES-GCM encryption.

OTP Recovery

Email-based one-time password verification used to reset the Pro Vault password.

Recovery Data

Encrypted server-side data that protects the vault key and allows password recovery.

🔄 When the Pro Vault password is reset using OTP verification, the existing vault key is preserved. Therefore, Version-2 encrypted files remain accessible after the password change.
