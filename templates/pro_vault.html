How Pro Vault Works

Pro Vault uses a user-specific vault key and browser-side AES-256-GCM encryption to protect uploaded files.

💾 Encrypted File Storage

Definitions

Pro Vault Password

A separate password used to unlock the Pro Vault. It is stored as a password hash and can be changed or recovered through OTP.

Vault Key

A randomly generated 32-byte key associated with the user. The same vault key remains in use when the Pro Vault password is changed.

AES-256-GCM

An authenticated encryption algorithm used by the browser to encrypt and decrypt file contents using the protected vault key.

Encrypted Storage

Uploaded files are stored in the database only as encrypted binary data. The original file contents are decrypted in the browser when the user downloads the file.

OTP Recovery

If the Pro Vault password is forgotten, the registered email address can be verified using a one-time password before setting a new vault password.

Password Change

Changing or resetting the Pro Vault password updates the password hash while preserving the existing vault key. Previously uploaded files therefore remain accessible.

The Pro Vault password is used for vault authentication. The vault key is separately protected by the server-side recovery mechanism. Files are encrypted using AES-256-GCM before storage.
