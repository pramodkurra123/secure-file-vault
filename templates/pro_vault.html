How Pro Vault Works

A single encryption system is used for all Pro Vault files.

👤 User
↓
🔑 Pro Vault Password
↓
🛡️ Protected Vault Key
↓
🔐 AES-256-GCM Encryption
↓
💾 Encrypted File Storage

Definitions

Pro Vault Password

The password used to unlock the user's Pro Vault.

Vault Key

A randomly generated 256-bit key used for Pro Vault file encryption.

AES-256-GCM

An authenticated encryption method used to protect the file contents.

Encrypted Storage

Files are stored in PostgreSQL as encrypted binary data rather than their original contents.

OTP Recovery

A six-digit one-time password sent to the registered email address for Pro Vault password recovery.

Password Change

Changing the Pro Vault password updates the password hash while preserving the same Vault Key. Existing encrypted files therefore remain accessible.

🔐 Security model:
The Pro Vault password is stored only as a password hash. The Vault Key is protected separately using the server's recovery key. Existing encrypted files are not re-encrypted when the password changes.
